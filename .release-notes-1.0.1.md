## dsh-mworks-ai 1.0.1

CI/maintenance release.

- Publish to npm from **npm Trusted Publishing (OIDC)** — no long-lived token. The workflow uses the repository secret `NPM_TOKEN` only when one exists, and OIDC otherwise; `workflow_dispatch` gained an `auth` input to force either mode.
- The workflow installs npm 11 (trusted publishing needs npm ≥ 11.5.1) and now uses `actions/checkout@v5` / `actions/setup-node@v5`.
- README: documented the release flow (`.github/workflows/npm-publish.yml`, tag must match `package.json`, versions already on npm are skipped).
- No plugin behaviour change: same tools, same UI section, same MCP rows.

**Full Changelog**: https://github.com/xiaobbl/dsh-mworks-ai/compare/v1.0.0...v1.0.1
